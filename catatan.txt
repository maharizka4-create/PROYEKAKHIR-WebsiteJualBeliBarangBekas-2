1. php artisan --version
Buat mengecek versi Laravel yang digunakan.
3. php artisan key:generate
Buat membuat APP_KEY aplikasi di file .env.
4. php artisan make:model Mahasiswa -m
Buat membuat Model Mahasiswa sekaligus file Migration.
5. php artisan migrate
Buat menjalankan Migration sehingga tabel dibuat di database.
6. php artisan migrate:status
Buat mengecek Migration mana yang sudah dijalankan.
7. php artisan migrate:rollback

Buat membuat Controller website dengan method CRUD.

10. php artisan make:request StoreMahasiswaRequest
Buat membuat file validasi saat menambah data.
11. php artisan make:request UpdateMahasiswaRequest
Buat membuat file validasi saat mengubah data.
12. php artisan install:api
Buat mengaktifkan dukungan routing API dan membuat routes/api.php jika belum ada.
13. php artisan route:list
Buat menampilkan seluruh route yang sudah terdaftar.
14. php artisan serve
Buat menjalankan website Laravel di localhost.
15. php artisan tinker
Buat mencoba perintah PHP dan menguji Model langsung lewat terminal.
16. php artisan optimize:clear
Buat membersihkan cache Laravel saat perubahan belum terbaca.

## 2. Membuat Database

Buka phpMyAdmin melalui Laragon, kemudian buat database:

`uts_mahasiswa`

Setelah itu, buka file `.env` dan sesuaikan bagian database:

```

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=uts_mahasiswa
DB_USERNAME=root
DB_PASSWORD=

```

Pastikan MySQL di Laragon sudah berjalan.

## 3. Membuat Model dan Migration

Di terminal VS Code, ketik:

```
php artisan make:model Mahasiswa -m
```

Perintah ini membuat:

- `app/Models/Mahasiswa.php`
- `database/migrations/xxxx_create_mahasiswas_table.php`

### A. Ngoding Migration

Buka file migration mahasiswa dan isi seperti berikut:

```

<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('mahasiswas', function (Blueprint $table) {
            $table->id();
            $table->string('nim')->unique();
            $table->string('nama');
            $table->string('prodi');
            $table->string('kelas');
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('mahasiswas');
    }
};

```

### B. Ngoding Model

Buka `app/Models/Mahasiswa.php`, lalu isi:

```

<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Mahasiswa extends Model
{
    protected $table = 'mahasiswas';

    protected $fillable = [
        'nim',
        'nama',
        'prodi',
        'kelas',
    ];
}

```

### C. Jalankan Migration di Terminal

Setelah migration disimpan:

```
php artisan migrate
```

Perintah ini membuat tabel `mahasiswas` di database.

## 4. Membuat Controller Website

Di terminal:

```
php artisan make:controller MahasiswaController --resource
```

Buka `app/Http/Controllers/MahasiswaController.php`, kemudian isi:

```

<?php

namespace App\Http\Controllers;

use App\Models\Mahasiswa;
use Illuminate\Http\Request;

class MahasiswaController extends Controller
{
    public function index()
    {
        $mahasiswas = Mahasiswa::latest()->get();

        return view('mahasiswa.index', compact('mahasiswas'));
    }

    public function create()
    {
        return view('mahasiswa.create');
    }

    public function store(Request $request)
    {
        $data = $request->validate([
            'nim' => 'required|string|unique:mahasiswas,nim',
            'nama' => 'required|string|min:3',
            'prodi' => 'required|string',
            'kelas' => 'required|string',
        ]);

        Mahasiswa::create($data);

        return redirect()->route('mahasiswa.index')
            ->with('success', 'Mahasiswa berhasil ditambahkan');
    }

    public function show(Mahasiswa $mahasiswa)
    {
        return view('mahasiswa.show', compact('mahasiswa'));
    }

    public function edit(Mahasiswa $mahasiswa)
    {
        return view('mahasiswa.edit', compact('mahasiswa'));
    }

    public function update(Request $request, Mahasiswa $mahasiswa)
    {
        $data = $request->validate([
            'nim' => 'required|string|unique:mahasiswas,nim,' . $mahasiswa->id,
            'nama' => 'required|string|min:3',
            'prodi' => 'required|string',
            'kelas' => 'required|string',
        ]);

        $mahasiswa->update($data);

        return redirect()->route('mahasiswa.index')
            ->with('success', 'Mahasiswa berhasil diperbarui');
    }

    public function destroy(Mahasiswa $mahasiswa)
    {
        $mahasiswa->delete();

        return redirect()->route('mahasiswa.index')
            ->with('success', 'Mahasiswa berhasil dihapus');
    }
}

```

## 7. Membuat CRUD API

Sekarang bagian Modul 3.

### A. Buat Controller API di Terminal

```
php artisan make:controller Api/MahasiswaController --api
```

### B. Buat Form Request

```
php artisan make:request StoreMahasiswaRequest
php artisan make:request UpdateMahasiswaRequest
```

### C. Isi `StoreMahasiswaRequest.php`

```

<?php

namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;

class StoreMahasiswaRequest extends FormRequest
{
    public function authorize(): bool
    {
        return true;
    }

    public function rules(): array
    {
        return [
            'nim' => 'required|string|unique:mahasiswas,nim',
            'nama' => 'required|string|min:3|max:150',
            'prodi' => 'required|string',
            'kelas' => 'required|string',
        ];
    }
}

```

### D. Isi `UpdateMahasiswaRequest.php`

```

<?php

namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;
use Illuminate\Validation\Rule;

class UpdateMahasiswaRequest extends FormRequest
{
    public function authorize(): bool
    {
        return true;
    }

    public function rules(): array
    {
        $id = $this->route('mahasiswa');

        return [
            'nim' => [
                'sometimes', 'required', 'string',
                Rule::unique('mahasiswas', 'nim')->ignore($id),
            ],
            'nama' => 'sometimes|required|string|min:3|max:150',
            'prodi' => 'sometimes|required|string',
            'kelas' => 'sometimes|required|string',
        ];
    }
}

```

### E. Isi `app/Http/Controllers/Api/MahasiswaController.php`

```

<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Http\Requests\StoreMahasiswaRequest;
use App\Http\Requests\UpdateMahasiswaRequest;
use App\Models\Mahasiswa;
use Illuminate\Http\Request;

class MahasiswaController extends Controller
{
    public function index(Request $request)
    {
        $query = Mahasiswa::query();

        if ($request->filled('cari')) {
            $query->where('nama', 'like', '%' . $request->cari . '%');
        }

        return response()->json(
            $query->latest()->paginate(10)->withQueryString(),
            200
        );
    }

    public function store(StoreMahasiswaRequest $request)
    {
        $mahasiswa = Mahasiswa::create($request->validated());

        return response()->json([
            'message' => 'Mahasiswa berhasil ditambahkan.',
            'data' => $mahasiswa,
        ], 201);
    }

    public function show(string $id)
    {
        $mahasiswa = Mahasiswa::find($id);

        if (!$mahasiswa) {
            return response()->json([
                'message' => 'Mahasiswa tidak ditemukan.',
            ], 404);
        }

        return response()->json([
            'data' => $mahasiswa,
        ], 200);
    }

    public function update(UpdateMahasiswaRequest $request, string $id)
    {
        $mahasiswa = Mahasiswa::find($id);

        if (!$mahasiswa) {
            return response()->json([
                'message' => 'Mahasiswa tidak ditemukan.',
            ], 404);
        }

        $mahasiswa->update($request->validated());

        return response()->json([
            'message' => 'Mahasiswa berhasil diperbarui.',
            'data' => $mahasiswa->fresh(),
        ], 200);
    }

    public function destroy(string $id)
    {
        $mahasiswa = Mahasiswa::find($id);

        if (!$mahasiswa) {
            return response()->json([
                'message' => 'Mahasiswa tidak ditemukan.',
            ], 404);
        }

        $mahasiswa->delete();

        return response()->json([
            'message' => 'Mahasiswa berhasil dihapus.',
        ], 200);
    }
}

```

### F. Daftarkan Route API

Buka `routes/api.php`.

```

<?php

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\Api\MahasiswaController;

Route::apiResource('mahasiswa', MahasiswaController::class);

```

Kalau `routes/api.php` belum tersedia pada project mentah Laravel, jalankan `php artisan install:api` terlebih dahulu. Perintah ini bisa memasang dependency tambahan.

## 8. Pengujian Terakhir

Jalankan perintah terminal:

```
php artisan route:list
```

Lalu jalankan Laravel jika belum aktif:

```
php artisan serve
```

Untuk website, buka:

`http://127.0.0.1:8000/mahasiswa`

Untuk API, gunakan Postman:

| Method | URL                |
| ------ | ------------------ |
| GET    | `/api/mahasiswa`   |
| POST   | `/api/mahasiswa`   |
| GET    | `/api/mahasiswa/1` |
| PUT    | `/api/mahasiswa/1` |
| DELETE | `/api/mahasiswa/1` |

Contoh Body JSON untuk POST:

```

{
    "nim": "250441100001",
    "nama": "Mahasiswa UTS",
    "prodi": "Teknik Informatika",
    "kelas": "3D"
}

```

Pada Postman, pilih Body → raw → JSON, dan tambahkan header `Accept: application/json`.
